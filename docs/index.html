Why it exists

Your hand needs a break. macOS makes that a chore.

If you're managing RSI, tendinitis, cubital tunnel, tennis elbow, or just a sprain, alternating hands is one of the simplest things you can do. But macOS buries the setting five steps deep — and you need it several times a day, usually at the exact moment your wrist is already complaining.

Features

Small on purpose.

HandSwitch does one thing and gets out of the way. No account, no telemetry, no background noise.

One click to switch

Left-click the menu bar icon and the primary button swaps. The icon shows the live mode — R or L.

A global shortcut

Hit ⌃⌥⌘M from any app. Prefer something else? Record your own in Settings.

Shortcuts & Siri

Four actions appear automatically in Shortcuts, Spotlight, and Siri. "Enable left-handed mode." Done.

Quiet confirmation

A native notification tells you which mode you're in, so you're never guessing. Turn it off anytime.

Starts with your Mac

Launch at login through the modern system API — no helper apps, no login-item hacks.

Accessible by design

VoiceOver labels, full keyboard navigation, Dynamic Type, and Reduce Motion support throughout.

How it works

It changes the real setting.

HandSwitch isn't a workaround layered on top of macOS. It writes the same system preference that System Settings does — then reads it back to confirm the change actually took.

Default

System setting

Flips the real macOS "Primary mouse button" preference. Persists across restarts, needs no permissions, and stays in sync if you change it in System Settings.

Optional

Instant

Swaps buttons live for an immediate switch on every macOS version. Requires Accessibility permission, which HandSwitch asks for only if you turn this on.

Install

Three steps.

  1. Download the DMG

    Grab the latest release and open it.

  2. Drag HandSwitch to Applications

    The installer window shows you exactly where it goes.

  3. Launch it

    There's no window — look for the 🖱 R / L icon in your menu bar.

First launch will be blocked — that's expected

Current builds aren't signed with an Apple Developer ID, so macOS stops them the first time. To open it: System Settings › Privacy & Security, scroll to the message about HandSwitch, and choose Open Anyway.

Prefer the terminal? xattr -dr com.apple.quarantine /Applications/HandSwitch.app

Questions

Good to know.

Does this actually change a macOS setting?

Yes. HandSwitch writes the same preference System Settings uses for "Primary mouse button", then reads it back to verify it applied. If macOS ever refuses, HandSwitch tells you plainly and offers to open System Settings — it never fails silently.

Does it work with a trackpad?

HandSwitch changes the primary mouse button, which is a separate setting from trackpad secondary click. If you use a trackpad, its right-click behaviour is configured independently in System Settings › Trackpad.

What permissions does it need?

None for the default mode. Accessibility permission is only requested if you switch on Instant mode, which swaps buttons live. Notifications are optional too.

Why does macOS say the app is damaged or blocked?

Because it isn't signed with a paid Apple Developer ID yet. The app is fine — Gatekeeper simply can't verify an unsigned developer. Use System Settings › Privacy & Security → Open Anyway. One side effect: because macOS ties Accessibility permission to an app's signature, you may need to re-grant it for Instant mode after an update.

Is it really free?

Yes — free, open source, and MIT licensed. No account, no telemetry, no analytics. You can read every line on GitHub.
